# LOREKEEPER-589 인증 전환 잔재 제거

2026-09-26, 서비스 토큰 포트·발급·재발급·폐기 코드와 기존 Redis 세션 어댑터,
JWT 키 로딩·설정을 제거했다. Google ID Token 검증과 OAuth 설정은 유지한다.
적용된 Flyway V1/V2 파일과 계정 계약은 변경하지 않았다.

서비스 JWT 키를 주입하지 않은 전체 테스트와 build·Spotless 검사를 통과했다.
Redis 7.4에서 최초 전체 검증 후 라우트·키 설정 부재 검사를 추가하고,
Valkey 9.0.6에서 전체 검증을 통과했다. 실제 HTTP 로그인·계정·폐기 테스트와
OAuth 서명·nonce·PKCE, DB 동시성 및 세션 경합 검증을 유지했다.

실행 안내와 통합 러너 갱신은 후속 Atomic 590에서 수행한다.
