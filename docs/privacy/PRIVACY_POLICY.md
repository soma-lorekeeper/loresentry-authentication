# Lore Sentry 개인정보 처리방침

> **책임:** 사용자에게 공개할 개인정보 처리 목적·항목·보유·외부 처리·권리행사 안내를 작성한다.
>
> **확인할 때:** 서비스의 개인정보 처리 내용을 사용자에게 안내하거나 공개 문안을 검토할 때.
>
> **관련 기준:** 서비스 이용 조건은 [이용약관](TERMS_OF_SERVICE.md), 동의 절차 구현은 [동의 설계](../account/TERMS_CONSENT_DESIGN.md)를 본다.

> 게시 전 초안. 확정한 운영 정책을 담으며 현재 구현 완료를 뜻하지 않습니다.
> 공개 전에 마지막 내부 확인 항목을 반영하고, 이 문서 안내와 내부 확인 절은 공개본에서 제외합니다.
> 시행일은 실제 최초 공개·적용일로 표시합니다.

소마 Lore Sentry 팀(이하 “운영자”)는 소설 에디터 Lore Sentry를 제공하면서
회원정보와 이용자가 입력한 정보를 아래와 같이 처리합니다.

## 1. 처리 목적·항목과 수집 방법

| 처리 목적 | 처리 항목 | 수집 방법 |
|---|---|---|
| Google 계정으로 회원 식별·연결 | Google 계정 식별자, 로그인 제공자, 서비스 내부 사용자 식별자 | 이용자가 요청한 Google 로그인과 서비스 계정 생성 |
| 계정정보 표시·관리와 주요 서비스 안내 | 이메일, 표시 이름, 계정 생성·수정 시각 | Google 로그인, 이용자의 표시 이름 수정, 서비스 이용 중 생성 |
| 로그인 요청 검증 | 로그인 요청 식별자와 요청 검증 정보, 생성·만료 시각 | 로그인 과정에서 생성 |
| 인증 후 약관 동의 절차 이어가기 | 서비스 내부 사용자 식별자, 동의 대기 식별정보, 대상 약관 버전, 생성·만료 시각 | Google 인증 완료 후 생성·임시 보관 |
| 로그인 상태 유지·보호 | 계정에 연결된 세션 식별정보와 생성·만료 정보 | 로그인 및 인증된 서비스 이용 중 생성 |

| 이미지 업로드·표시 | 업로드한 이미지, 파일명·유형·크기, 저장 위치와 업로드 상태, 프로젝트 연결정보 | 이용자의 업로드 |
| 작업환경 유지 | 메모, 즐겨찾기, 작업공간 설정 | 이용자의 입력·설정 |
| 요청한 소설 분석 | 분석 대상 원고와 그로부터 생성한 인물·관계·사건·요약 등 분석 결과 | 이용자가 분석 버튼을 눌러 요청 |
| 문의·권리행사 처리 | 회신 이메일, 문의 내용, 요청 처리에 필요한 계정 확인정보와 처리 결과 | 문의 이메일 및 제공되는 문의 기능 |

Google 인증 후 계정을 생성·조회하며, 약관에 동의하지 않고 화면을 닫아도 계정정보는
유지됩니다. 동의 대기 정보의 만료는 계정 삭제를 의미하지 않습니다.

Google에서 이메일이나 이름이 제공되지 않을 수 있습니다. 이름은 최초 표시 이름 설정에
사용하며, 표시 이름은 이용자가 변경할 수 있습니다. 프로필 이미지나 이미지 URL은 회원정보로
저장하지 않습니다. 소설 원문에 실제 개인을 식별할 수 있는 정보가 포함되면 해당 부분도
개인정보 처리 대상이 될 수 있습니다.

회원 식별에는 Google 계정 식별자를 사용합니다. 이메일은 계정 연락처와 주요 약관 변경·
서비스 종료 안내에 사용하고, 표시 이름은 서비스 내 계정 표시에 사용합니다. 재로그인 시
Google이 제공한 이메일을 갱신하지만 이용자가 설정한 표시 이름을 Google 이름으로 덮어쓰지 않습니다.
광고·마케팅을 위한 이메일 발송은 현재 운영 범위에 포함하지 않습니다.

## 2. 개인정보 처리의 근거

회원 식별·인증과 이용자가 요청한 가입 및 에디터 기능 제공에 필요한 개인정보는
[개인정보 보호법 제15조 제1항 제4호](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335387)의 계약 체결·이행 근거로 처리합니다.
그 범위에 포함되지 않는 처리가 필요해지면 적법한 근거를 마련하고, 동의가 필요한 경우
처리 목적·항목·보유기간과 거부 시 영향을 알린 뒤 별도로 동의받습니다.

이용약관 동의와 개인정보 수집·이용 동의는 서로 구분됩니다. 이 처리방침은 개인정보
처리 내용을 공개하는 문서이며, 처리방침 열람 자체를 별도 동의로 간주하지 않습니다.

| 로그인 세션 정보 | 마지막 인증 활동 후 14일 만료·활동 시 연장. 로그아웃 시 해당 세션 폐기, 탈퇴 시 해당 계정의 세션 폐기 |

보유 목적이 끝난 정보는 대상과 보존 예외를 확인한 뒤 복구·재생되지 않도록 파기합니다.
작품 영구 삭제 시 원문에 연결된 문서 버전·이미지·분석 결과도 함께 정리합니다. 탈퇴 시
계정·Google 연결정보·동의 기록과 모든 프로젝트의 원고·문서 버전·이미지·분석 결과·
작업환경 정보를 별도 복구 유예기간 없이 지체 없이 삭제하고 로그인 세션과 동의 대기를 폐기합니다.
문서 버전과 휴지통은 에디터의 복원 기능이며 별도 재해 복구용 백업이 아닙니다.
외부 처리업체의 보관분은 해당 업체에 대해 공개한 보관기간과 삭제 조건을 적용합니다.

현재 결제 기능이 없어 구매·결제 내역을 수집하지 않습니다. 다른 법령에 따라 별도 보존이
필요한 정보가 확인되면 해당 법령·항목·목적·기간을 공개하고 일반 서비스 이용 정보와
분리해 보관합니다.

## 4. 소설 원문과 외부 AI 분석

운영자는 이용자의 원고를 저장·편집하고 이해하기 쉬운 형태로 분석하는 기능을 제공합니다.
원고와 분석 결과를 다른 사용자에게 공개하거나 운영사의 광고·판매·모델 학습 목적으로 이용하지 않습니다.

이용자가 분석 버튼을 눌러 요청한 경우에 분석 대상 소설 원문을 OpenAI API로 전송합니다.
원고 저장만으로 자동 분석을 실행하지 않습니다. 회원의 이메일·표시 이름·Google 계정
식별자·서비스 사용자 ID·로그인 인증 정보는 함께 보내지 않습니다.
다만 원문 자체에 실제 개인을 식별할 정보가 포함될 수 있으므로 이를 계정정보와 별도로 검토합니다.

OpenAI API 데이터는 기본적으로 모델 학습에 사용되지 않으며, 운영자는 학습을 위한 선택적
데이터 공유를 허용하지 않습니다. 다만 일반 API 설정에서는 입력·출력이 포함될 수 있는 악용
방지 로그가 기본 최대 30일 보관되고, 법적 필요나 서비스·제3자 보호를 위한 예외가 있습니다.
API 기능·모델·설정에 따라 응답 상태나 캐시의 별도 보관도 발생할 수 있습니다.

운영 목표는 외부 업체의 원고·분석 결과 무보관입니다. Zero Data Retention(ZDR)의 승인과
적용 여부, 사용하는 모델·기능의 보관 예외를 확인한 뒤 실제 조건을 안내합니다.
응답 저장을 끄는 설정만으로 모든 보관이 없어지는 것은 아니며, 현재 무보관을 보장하지 않습니다.
미국에서 처리하는 구성을 검토하되, OpenAI를 사용한다는 이유만으로 처리 국가를 미국으로 확정하지 않습니다.

확인 기준: [OpenAI 공식 데이터 정책](https://developers.openai.com/api/docs/guides/your-data), 2026-09-29 확인.
출시 시 실제 계정 설정·계약과 다시 대조합니다.

## 5. 제3자 제공·처리위탁·국외 이전

회원정보와 원고를 광고·판매 목적으로 제3자에게 제공하는 것은 서비스 운영 범위에 포함하지 않습니다.
외부 업체가 서비스 제공을 위해 정보를 처리하는 경우에는 실제 계약과 처리 목적에 따라
처리위탁 또는 제3자 제공 여부를 구분합니다. 국외에서 개인정보가 처리되는 경우에는
해당 이전의 법적 근거와 상세 내용을 안내합니다.

다음 업체를 사용하는 구성을 기준으로 안내합니다. 계약 법인·연락처, 업체별 보유기간과
국외 이전의 구체적인 국가·근거는 아래 내부 운영 확인을 마친 뒤 공개본에 반영합니다.

| 업체·서비스 | 처리 목적과 범위 | 저장·전송 위치 확인 범위 |
|---|---|---|
| Amazon Web Services(AWS) | 서버 실행, 회원·에디터 데이터와 이미지 저장, 웹사이트·이미지 전송 | 저장소 설정상 RDS·Neptune·이미지 S3는 대한민국 서울 리전. CloudFront 전송·캐시 위치까지 국내로 한정한다는 의미는 아님 |
| Cloudflare | API 접속 중계·보호 | 접속 경로에 포함됨. 실제 프록시·로그·지역 설정은 계정에서 확인 필요 |
| OpenAI API | 이용자가 요청한 원고 분석 | 분석 버튼 실행 시 원문을 API로 전송. 처리 국가·보유기간은 제4조의 실제 적용 조건 확인 필요 |

Google은 이용자가 선택한 로그인 제공자입니다. Google 인증으로 받은 계정 식별자·
이메일·이름을 제1조의 목적에 사용하며, 소설 원문을 Google 로그인 API로 전송하지 않습니다.

분석을 실행하지 않으면 해당 OpenAI 원고 전송은 발생하지 않습니다. 이 선택은
서비스 접속·저장에 사용하는 인프라 업체의 처리와는 별개입니다.

개인정보 국외 이전에 별도 동의가 필요한 경우에는 이전 전에 구분해 동의받습니다.

## 6. 쿠키와 브라우저 저장소

서비스는 Google 로그인 요청 연결, 약관 동의 절차, 로그인 상태 유지에 쿠키를 사용합니다.

이용자는 브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있습니다. 필수 인증 쿠키를
차단하면 로그인 또는 가입 절차를 이어갈 수 없습니다.

| 운영 환경의 쿠키 | 목적 | 수명 |
|---|---|---|
| `__Host-ls_oauth` | Google 로그인 요청과 콜백 연결 | 최대 5분 |
| `__Host-ls_session` | 로그인 상태 유지 | 최대 14일. 인증 활동 시 갱신 |
| `__Host-ls_consent` | 인증 후 약관 동의 대기 | 생성부터 최대 30분. 동의 완료 시 삭제 |

인증 쿠키는 브라우저 스크립트로 읽을 수 없도록 설정합니다. 테마·편집기 설정은
브라우저에 저장하며 사이트 데이터를 삭제하면 제거됩니다. 개발·데모 모드에서는 데모 원고와
연결 설정도 브라우저에 남을 수 있습니다. 서버의 회원 탈퇴로 브라우저 저장 데이터까지
삭제되지는 않습니다. 현재 서비스에 광고·행동 분석 도구는 도입하지 않았습니다.

## 7. 이용자의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지를 요청할 수 있으며,
동의에 근거한 처리가 있다면 해당 동의를 철회할 수 있습니다. 법정대리인 등 대리인을 통한
요청은 본인과 대리 권한을 확인하는 절차를 거쳐 처리합니다.

요청은 제9조의 문의 이메일로 접수하며, 서비스 내 문의하기 기능이 제공되면 그 기능으로도
